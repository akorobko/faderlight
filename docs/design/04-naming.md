# 04 — Project name

## Constraints

Do **not** use, as or inside the product name, repo name, plugin UUID or icon: **RME**, **TotalMix**, **Fireface**, **DIGICheck**, **ARC**, **Elgato**, **Stream Deck** (also avoid the word *Deck* as a lead brand element), **Mackie**. Nominative use is fine in descriptions ("Controls RME TotalMix FX from an Elgato Stream Deck. Not affiliated with RME or Elgato.").

Also avoid: **MixKey** (Steinberg product), "TotalMix FX Control" (existing plugin).

## Recommendation: **Faderlight**

- Evokes the product exactly: a lit fader/channel strip on an LCD key.
- No hits for the exact term in web search; npm package name free (2026-11-09).
- Works as repo (`faderlight`), plugin UUID (`dev.faderlight.mixer`), and Marketplace name ("Faderlight for TotalMix FX" — nominative, allowed style).
- Easy to say, no language collisions known.

## Before creating the repo

These are preliminary checks, not legal clearance. Before public release do a 10-minute check of: USPTO TESS / EUIPO eSearch (classes 9 and 42), GitHub name search, Elgato Marketplace search, and domain availability.
