# 03 — UX design: keys, gestures, layouts, settings

## 1. Design principles

1. **Glanceable at 96 px.** Max 3 text sizes; numbers ≥ 26 px (on the 144 canvas); state by colour *and* shape (colour-blind safe).
2. **TotalMix colour language** so the deck reads like the mixer: mute = cyan/teal, solo/PFL = orange, 48V = red, record = red, active control room = blue-grey. (Colours are ours; no RME artwork or logos.)
3. **One key = one channel.** Everything about a channel that matters during a session fits on its key; details are one long-press away.
4. **Never lie.** Unconfirmed state is drawn with a dashed outline; disconnected state greys everything and shows a reconnect hint.
5. **Safe destructive actions.** Phantom on, snapshot save, global mute need long-press or confirm-tap.

## 2. Key anatomy (144 × 144 canvas)

The canvas sits inside a 14 px margin on every side (a 172 px key, scaled to the device). An XL's plastic keycaps bend the edge of the display, so text and icons stay on the canvas and meters reach at most 1 px past it. Colour never reaches the key's edge either: a colour band or a frame there bends into odd shapes. A state's colour (muted, soloed, lit) goes on a **pad** instead: the canvas and 3 px of the margin, with round corners, and the rest of the margin keeps the plain background. (From the first two looks at the keys on a real XL.)

### 2.1 Input channel key

```
┌───────────────────────────┬──┐
│ Vocal                     │▐▐│  ← 1. name, big, one line (alias > TotalMix name > physical label)
│ ▀▀▀▀▀                     │▐▐│     underlined in the TotalMix channel colour
│ +42 dB                    │▐▐│  ← 2. primary value (configurable: gain | fader | send to selected submix)
│ →| GAIN              [M]  │▐▐│  ← 3. type icon and caption; M and S chips on the right
│                           │▐▐│  ← 4. stereo meter L/R, −60…0 dBFS, peak-hold tick, clip cap turns red
│ [48V] [INST] [Ø] [AS]     │▐▐│  ← 5. badge row (only badges the channel supports; lit when active)
└───────────────────────────┴──┘
     M / S state = tinted pad (see below)
```

- **Name**: one line. The physical label ("MIC 9") shows only when the channel has no name; Channel Detail shows it on its meter key.
- **Colour**: an underline below the name, as wide as the name, in the channel's TotalMix colour. TotalMix colours its name fields' text; a colour band behind the name bent at the key's edge. No colour: no underline. Muted dims it.
- **Type icon**, before the caption: an arrow into a port (hardware input), a screen (software playback), a speaker (hardware output), headphones (Phones).
- **Sizes**: the name is the biggest text, then the value. Badges and chips are 25 px high, so 48V and INST read at a glance.
- **Meter**: right edge, 11 px each L/R (mono = one 16 px bar), reaching 1 px into the margin. Segments: green < −18, yellow −18…−6, orange −6…−1, red ≥ −1 dBFS. Peak-hold line 1.5 s; clip cap latched 3 s (or until tapped in detail view). Two bars are a stereo pair, so there is no ∞ badge.
- **Mute**: a teal pad, strong enough to see from across the room (a darker one was too subtle on the XL), name & value turn pale teal, a cyan **M** chip on the caption row; meter still runs (pre-fader input signal remains useful) but dimmed.
- **Solo/PFL**: an amber pad as strong as the mute teal + **S** chip. Muted and soloed: the teal pad and both chips.
- **48V on**: red **48V** badge filled (outline when off). **INST**, **Ø** (phase), **AS** (AutoSet) when on.
- **Pending** (sent, not confirmed): dashed frame along the pad's edge. **Unknown/disconnected**: grey, value "––".
- **Signal present** (> −50 dBFS) without meter mode → small green dot top right (for "minimal" style).

Styles per key (settings): **Full** (above), **Meter** (big vertical meter + name, for monitoring walls), **Minimal** (name + state only, big text).

### 2.2 Output / Monitor keys

Laid out like the input key: the output's name big (or its physical label), the colour underline, the volume, then the role as the caption ("MAIN", "PHONES 1", "OUTPUT", or "VOLUME" when the name already says it) beside a speaker or headphone icon.

- **Main Out key**: volume ("−18.5 dB"), stereo meter, chips **DIM** (amber when active), **MONO**, **B** (Speaker B), **EXT**, **TB** (talkback) in the badge row. Muted → teal pad like inputs.
- **Phones key** (PH 9/10, PH 11/12): headphone icon + level + meter + mute. A Phones role TotalMix shows no output for (none set up, or its output hidden) is a blank key. A Main key in that case says "Not assigned".
- **Output channel key**: same as Main without monitoring chips.
- **Volume step keys** (▲/▼): show target name + current dB; press-and-hold repeats with acceleration (0.5 dB → 1 dB → 3 dB per tick).

### 2.3 Other keys

| Key | Shows | Tap | Long-press |

| Status | link word + heartbeat dot, device name large; sample rate, clock lock (green/red), DSP % when reported | open Control Center | force resync (`/sendall`) |

## 3. Gestures

| Gesture | Detection | Default on channel key | Configurable |
|---|---|---|---|
| **Tap** | keyUp < 450 ms | Mute toggle (inputs, outputs) | yes: mute, solo, 48V, phase, select, none |
| **Long-press** | held ≥ 450 ms (fires on threshold, haptic-like flash) | **Open Channel Detail overlay** | yes: detail, solo, 48V (safe), autoset |
| **Double-tap** | 2nd tap within 250 ms | off by default (adds latency to tap) | solo, reset to 0 dB, … |
| **Hold-repeat** | ± keys only | step with acceleration | step size, curve |

### 3.1 Channel Detail overlay (drill-down)

Long-press any channel key → the **whole deck** (when on the Console profile) becomes that channel's control surface for that channel. On non-Console profiles, it switches to the bundled Console profile, then returns on Back.

```
 ┌────────┬────────┬────────┬────────┬────────┬────────┬────────┬────────┐
 │ ◀ BACK │ MIC 9  │ GAIN − │ GAIN + │  48V   │   Ø    │  INST  │AUTOSET │
 │        │ Vocal  │ +42 dB │        │        │        │        │        │
 ├────────┼────────┼────────┼────────┼────────┼────────┼────────┼────────┤
 │  MUTE  │  SOLO  │ FADER− │ FADER+ │ METER  │ LOWCUT │   EQ   │  DYN   │
 │        │        │ −5.0dB │        │ (tall) │ 80 Hz  │  on    │  off   │
 ├────────┼────────┼────────┼────────┼────────┼────────┼────────┼────────┤
 │ → MAIN │ → PH1  │ → PH2  │ → AN3/4│ → ADAT │ FX SND │  PAN   │  PAN   │   ← send level into each submix;
 │ −5.0   │ −12.0  │  −∞    │  −∞    │  −∞    │ −20 dB │   ◀    │   ▶    │      tap = select submix for ± keys
 ├────────┼────────┼────────┼────────┼────────┼────────┼────────┼────────┤
 │ ◀ PREV │ NEXT ▶ │ SEND − │ SEND + │ RENAME*│        │ CLEAR  │ ◀ BACK │
```

*Rename opens Control Center on that channel (Global OSC supports writing names).
Auto-return to the console after 20 s of inactivity (configurable, off allowed).

## 4. Default Stream Deck XL layout ("Console" page)

```
 Row 1  │ SNAP 1 │ SNAP 2 │ SNAP 3 │ SNAP 4 │ SNAP 5 │ SNAP 6 │ STATUS │ PAGE ▶ │
 Row 2  │ IN     │ IN     │ IN     │ IN     │ IN     │ IN     │ IN     │ BANK ▶ │  ← inputs, 7 wide
 Row 3  │ PB     │ PB     │ PB     │ OUT    │ OUT    │ OUT    │ OUT    │ BANK ▶ │  ← playback, then outputs
 Row 4  │ MAIN   │ PH 1   │ PH 2   │ MAIN ⟲ │  DIM   │  MONO  │        │ EXIT   │
```

Revised after the first run on a real XL (2026-11):

- **Each channel row ends in the Bank key that moves it**, so the row shows 7 strips and Bank steps 7. Row 2 follows the inputs TotalMix shows; row 3 the playback strips, then the outputs that are not Main or a Phones output (those have keys of their own in row 4). A small setup fits without banking: while a row's own source fits, its Bank key is blank. Once a long press has switched the row to another source, the key stays, so it can switch back.
- **The top-right key is the page key on every page.** On the Console it shows the next page's name; on the overview pages it reads "Console" and goes back. A long press on any page key goes to the Console too.
- **Exit** (bottom right) leaves the Console for the profile the deck showed before.
- **Dim and Mono** sit with Main on the bottom row, so the top row has room for six snapshots.
- **MAIN ⟲** is a Level Preset for Main: a tap sets the saved level, a long press saves the current one. It is lit while Main is at that level.
- Left out of the default page, but available as actions: the ± Volume Step keys, Talkback, Global Mute and Global Solo. TotalMix's Global Mute and Solo are master switches (lit whenever any mute or solo is set anywhere, a press switches all of them off and on again), which on the Console page only repeated what the channel keys show.
- A Phones key without an output in TotalMix is blank, instead of looking offline.

Additional default pages: **Inputs** (29 input keys, meter style, its bank and a page key to Outputs) and **Outputs** (23 output keys, Dim, Mono, Speaker B, External, its bank and a page key to Inputs); **Recording** (DURec + record-arm + meters) later. Users rearrange in the Control Center layout builder; the Stream Deck app only ever sees one profile full of Slots.

## 4a. Mixed mode: a few keys on your own page + "open full console"

The Console profile is optional. Most users will share their main page with other things:

```
 Your own page (any profile)
 │ OBS... │ Zoom.. │ MIC 9  │ MIC 10 │  DIM   │ G.MUTE │ SNAP 1 │ SNAP 2 │
 │ ...    │ ...    │ ...    │ ...    │  ...   │ ...    │ SNAP 3 │CONSOLE▶│
```

- Every key type exists as a **standalone action** (Channel, Main/Output, Phones, Snapshot, Monitor toggle, Global Mute/Solo, Status, Volume step, Level Preset, Exit Console) that you drag onto any page in the Stream Deck app. They render exactly like Console keys and keep their own settings (target, tap, long-press, style).
- **Console launcher** action: switches the deck to the bundled full Console profile. Its key shows the Faderlight mark and the interface's name (a mini status, with the active snapshot and a clip warning, may follow).
- **Exit** on the Console returns to the page you came from (SDK `switchToProfile` without a profile name returns to the previous profile **[VERIFY on SDK v3]**). Auto-return after idle is optional.
- **Long-press a standalone channel key** opens the Channel Detail overlay on the Console profile, then Back returns to your page.
- Standalone keys and Console keys share one connection and one state store, so mixing them costs nothing extra.

## 5. Settings: three levels

Stream Deck's PI is a narrow webview only visible while a key is selected, with limited widgets. So configuration is split:

### 5.1 Property Inspector (in Stream Deck app) — "just enough"

For a **Slot** on the Console profile:
- Header: what this slot currently is (read-only) + **[Open Control Center]** button.

For a **specific action** (Channel / Monitor / Snapshot …) on any profile:
- *Target* — searchable select fed live from the device (`IN · MIC 9 · Vocal`, grouped by row), so users pick by name, not index.
- *Tap* / *Long-press* behaviour selects.
- *Primary value* (gain | fader | send→submix) and *Style* (Full | Meter | Minimal).
- Connection status line ("● Connected to Fireface UFX III · 48 kHz") and **[Open Control Center]**.

### 5.2 Control Center (local web app, opened in browser) — the real settings dialog

Left nav, five sections:

1. **Connection** — host, ports, multiple TotalMix instances (later), *Setup Assistant*: step-by-step TotalMix checklist with live checks (✓ feedback received, ✓ status heartbeat, ✓ level data arriving, ✗ "Send changes" seems off → fix hint). Packet log viewer (last 500 messages, filter).
2. **Device & Channels** — detected device, sample rate, per-row channel table with live meters: show/hide, alias, custom colour, key style default, mono/stereo display.
3. **Layout** — 8×4 grid per page (mirrors the deck, live-rendered with real key images), drag channels/functions from a palette, add/rename/reorder pages, bank behaviour (which rows the Bank keys move). Templates: Studio Console, Tracking, Monitoring only.
4. **Behaviour** — gesture timings (long-press ms, double-tap on/off), tap/long-press defaults per key type, step sizes & acceleration, detail-overlay timeout, confirmation for destructive actions.
5. **Appearance** — theme (dark / high contrast), meter scale (−60/−40 dBFS), ballistics (peak hold, decay, clip hold), meter fps (budget), font scale, badge set.

Plus **Backup**: export/import JSON; reset to defaults.

Built so far (M5.3, M5.4): Connection as above; Device & Channels with the interface, snapshot
names (which win over the names read from TotalMix's state file), and per channel a live meter,
show/hide in the Console's banks, alias and custom colour, plus the Level Preset levels;
Behaviour with the gesture timings (long press, double tap, repeat) and the overlay timeout;
Appearance with the theme, a key colour for each TotalMix colour number (only 1, 3, 5 and 6 are
known), and the frame rates. Not built yet: sample rate, key style default and mono/stereo
display per channel, per-type tap/long-press defaults, step sizes, confirmations, meter scale
and ballistics, font scale, badge set.

### 5.3 Global settings auto-applied

Everything in Control Center is stored in Stream Deck global settings → survives restarts, backs up with Stream Deck profiles.

## 6. Accessibility & robustness

- Shapes + letters for all states (M/S chips, filled vs outline badges).
- High-contrast theme.
- When TotalMix isn't running: every key shows a grey "TotalMix offline" pattern; Status key shows the reason (no packets / wrong port / TotalMix OSC disabled).
