# Captures

Real TotalMix FX Global OSC traffic recorded with `tools/capture` (see its README for how to
record one and for the file format). Name: `<device>-<totalmix-version>-<date>.jsonl`.

These are our own recordings, so they may be committed (unlike RME documents in
`docs/vendor/`). Treat them as read-only test data: re-record instead of editing.
